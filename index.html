Project Overview

The Microsoft Cloud Administration Lab is a structured hands-on learning project designed to develop practical skills in Microsoft cloud technologies and enterprise IT support.

The lab simulates a real-world business environment where users, devices, applications, identities, and collaboration services are managed and supported using Microsoft's cloud platforms.

The project focuses on Microsoft Entra ID, Microsoft 365, Exchange Online, Microsoft Teams, Microsoft Intune, SharePoint Online, and Microsoft 365 Apps through administration and troubleshooting scenarios.

Project Goal

To develop the practical administration, troubleshooting, and support skills required to effectively manage Microsoft cloud environments in Level 1/Level 2 IT Support, Service Desk, Microsoft 365 Administration, and Cloud Support roles.
