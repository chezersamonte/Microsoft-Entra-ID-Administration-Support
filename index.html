Project Overview & Goal

📖 Project Overview

The Microsoft Entra ID Administration & Support Lab is a structured hands-on learning project designed to develop practical skills in Microsoft Entra ID administration, identity and access management, and enterprise IT support.

The lab simulates a real-world business environment where user accounts, groups, authentication, devices, enterprise applications, and administrative roles are managed using Microsoft Entra ID.

The project focuses on real-world administration, configuration, and troubleshooting tasks commonly performed by Level 1 and Level 2 Microsoft Entra ID Support Engineers.

🎯 Project Goal

To build the practical administration, identity management, security, and troubleshooting skills required to support Microsoft Entra ID environments in Level 1 and Level 2 IT Support, Help Desk, Service Desk, and Cloud Support roles.

Microsoft Entra ID User Management

User Creation & Access Control

Learn the essential user management tasks in the Microsoft Entra admin center, including creating, managing, securing, and restoring user accounts.

Create User

Create new cloud user accounts by configuring the user's name, username, password, profile information, and optional license assignments.

Edit User Information

Update user profile information including display name, job title, department, office location, contact details, and other account properties.

Reset Password

Reset a user's password, generate a temporary password, and require the user to change it during their next sign-in.

Enable / Disable User

Control user access by enabling or disabling sign-in without permanently deleting the account from Microsoft Entra ID.

Delete User

Remove user accounts from Microsoft Entra ID while retaining them temporarily for recovery during the retention period.

Restore Deleted User

Recover recently deleted users along with their account information before the permanent deletion period expires.

Revoke Sessions

Invalidate all active user sessions and require the user to authenticate again across Microsoft 365 services and applications.

Bulk Operations

Access bulk management tools for creating users, downloading user lists, deleting accounts, and monitoring bulk administrative tasks.

Manage Roles

Assign or remove Microsoft Entra administrator roles to grant users the permissions required to perform administrative tasks.

Manage Group Membership

View group memberships, add or remove users from Security Groups and Microsoft 365 Groups, and verify group-based access.

View Assigned Licenses

Review assigned Microsoft 365 licenses, available service plans, and verify whether users have access to licensed applications.

Manage User Devices

View registered and joined devices, verify ownership, monitor device status, and manage device records associated with users.

Manage Authentication Methods

Review or manage authentication methods including Microsoft Authenticator, phone numbers, FIDO2 security keys, and passwordless sign-in.

Create Temporary Access Pass

Create a Temporary Access Pass to help users securely register new authentication methods or recover access to their account.

View User Audit Logs

Review administrative changes made to user accounts, including password resets, role assignments, profile updates, and license modifications.

View User Sign-in Logs

Analyze user sign-in activity, authentication status, locations, devices, client applications, and Conditional Access evaluation results.

Manage Assigned Manager

Assign or update a user's manager to support organizational hierarchy, approval workflows, and Microsoft 365 collaboration features.

Upload Bulk Users

Create multiple user accounts at once by uploading a properly formatted CSV file using Microsoft Entra bulk user management.

Bulk Operation Results

Monitor completed bulk operations, review successful and failed actions, and download detailed error reports for troubleshooting.

View & Understand User Settings

Explore tenant-wide user settings that control self-service capabilities, application registration, group creation, guest access, and user permissions.

Microsoft Entra ID Group Management

Group Creation & Management

Learn the essential group management tasks in the Microsoft Entra admin center, including creating security groups, managing members, restoring deleted groups, and administering Microsoft 365 groups.

Create Security Group

Create security groups to simplify permission management, assign access to resources, and manage users or devices collectively instead of individually.

Add Group Members

Add users, devices, service principals, or other supported objects to Security Groups or Microsoft 365 Groups to grant access and collaboration capabilities.

Remove Group Members

Remove members from groups when they no longer require access to shared resources, applications, or organizational permissions.

Delete Group

Permanently remove unused or obsolete Security Groups and Microsoft 365 Groups that are no longer required within the organization.

Restore Deleted Group

Recover recently deleted Microsoft 365 Groups during the retention period, including their members, conversations, and associated resources.

View Group Members

Review all users, devices, or other directory objects assigned to a group and verify current membership information.

Manage Group Owners

View, add, or remove group owners responsible for managing memberships, updating group settings, and administering Security Groups or Microsoft 365 Groups.

Create Microsoft 365 Group

Create Microsoft 365 Groups to enable collaboration across Outlook, Microsoft Teams, SharePoint, Planner, and other Microsoft 365 services.

Create Dynamic Group

Create Dynamic Security Groups or Dynamic Microsoft 365 Groups that automatically update membership based on Microsoft Entra user or device attributes.

Configure Dynamic Membership Rules

Create and modify dynamic membership rules using user or device properties such as department, job title, country, or operating system to automate group membership.

Configure Group-based Licensing

Assign Microsoft 365 licenses to Security Groups so users automatically receive or remove licenses when they join or leave the group.

Configure Group Settings

Manage group configuration settings including naming policies, group expiration, creation permissions, guest access, and ownership management for Microsoft Entra groups.

Microsoft Entra ID Administrator Roles

Understanding Administrative Roles & Basic Management

Learn the essential administrator role management tasks in the Microsoft Entra admin center, including role-based access control (RBAC), privileged access concepts, role assignments, and administrative access management.

Understand Role-Based Access Control (RBAC)

Learn how Role-Based Access Control (RBAC) assigns permissions through built-in administrator roles, ensuring users receive only the access required to perform their administrative responsibilities.

Understand Privileged Access Concepts

Explore privileged accounts, privileged roles, privileged identity management concepts, and security practices used to protect highly sensitive administrative accounts.

Understand the Principle of Least Privilege

Learn the Principle of Least Privilege by assigning only the minimum permissions users need, reducing security risks while maintaining operational efficiency.

Common Administrator Roles

Become familiar with commonly used Microsoft Entra administrator roles, including Global Administrator, User Administrator, Password Administrator, Groups Administrator, and Helpdesk Administrator.

Assign Administrator Roles

Assign built-in administrator roles to users, granting the permissions necessary to perform specific administrative tasks within Microsoft Entra ID and Microsoft 365.

Remove Administrator Roles

Remove administrator role assignments when elevated permissions are no longer required, helping maintain a secure and compliant administrative environment.

Manage Role-Assignable Groups

Manage role-assignable groups that simplify administrator role assignments by allowing privileged roles to be granted through secure group membership.

Verify Administrator Access

Verify assigned administrator roles, review effective permissions, and confirm that users have the appropriate level of administrative access within Microsoft Entra ID.

Microsoft Entra ID Multi-factor Authentication (MFA)

MFA Configuration & Support

Learn the essential Multifactor Authentication (MFA) administration tasks in the Microsoft Entra admin center, including enabling MFA, managing authentication methods, configuring authentication policies, reviewing registration reports, and protecting user accounts with Conditional Access.

Enable or Disable MFA per User

Enable or disable per-user Multifactor Authentication (MFA) for individual users using the classic MFA management portal.

View User's MFA Status

View whether a user's per-user MFA status is Disabled, Enabled, or Enforced to verify their MFA configuration.

Reset or Delete a User's MFA Methods

Reset or remove a user's registered authentication methods, allowing them to register new MFA methods when existing methods are unavailable or compromised.

Require Users to Re-register MFA

Require users to register their authentication methods again during their next sign-in after replacing devices or recovering account access.

View a User's Registered Authentication Methods

View all authentication methods registered by a user, including Microsoft Authenticator, phone numbers, FIDO2 Security Keys, passkeys, and Temporary Access Pass.

Add Authentication Methods for a User

Add supported authentication methods, such as phone numbers or Temporary Access Pass (TAP), to help users securely access or recover their accounts.

Configure Authentication Methods Policy

Configure which authentication methods users can register and use, including Microsoft Authenticator, SMS, Voice Calls, FIDO2 Security Keys, Passkeys, and Temporary Access Pass.

Review MFA Registration Details and Authentication Method Reports

Review MFA registration details and authentication method reports to monitor user registration, adoption, and authentication method usage across the organization.

Enable or Disable Microsoft Authenticator

Enable or disable Microsoft Authenticator as an authentication method for Multifactor Authentication (MFA) and passwordless sign-in.

Configure Microsoft Authenticator Settings

Configure Number Matching, Location Context, and App Context to improve Microsoft Authenticator security and protect against MFA fatigue attacks.

Enable or Disable SMS Authentication

Enable or disable SMS authentication, allowing users to verify their identity using one-time verification codes delivered by text message.

Enable or Disable Voice Call Authentication

Enable or disable voice call authentication, allowing users to verify their identity through automated phone calls.

Enable or Disable FIDO2 Security Keys

Enable or disable FIDO2 Security Keys to provide phishing-resistant passwordless authentication using supported hardware security keys.

Manage Temporary Access Pass (TAP)

Create, manage, and revoke Temporary Access Passes (TAP) to help users register authentication methods or recover secure access to their accounts.

Create a Conditional Access Policy that Requires MFA

Create Conditional Access policies that require Multifactor Authentication (MFA) for selected users, groups, cloud apps, or sign-in scenarios.

Enable or Disable Security Defaults (MFA Enforcement)

Enable or disable Microsoft Entra Security Defaults, which provide baseline security by enforcing MFA, protecting administrator accounts, and blocking legacy authentication.

Microsoft Entra ID Conditional Access

Conditional Access Configuration & Support

Learn the essential Conditional Access administration tasks in the Microsoft Entra admin center, including creating and managing policies, configuring user and application assignments, defining conditions and access controls, testing policies safely using Report-only mode, and validating policy results through Sign-in Logs.

View, Create, and Manage New and Existing Policies

Create, edit, enable, disable, and manage Conditional Access policies to protect users, applications, and organizational resources.

View & Configure User and Group Assignments

Configure which users, groups, directory roles, or guest users are included or excluded from Conditional Access policies.

View & Configure Target Resources

Select the cloud applications, user actions, or authentication contexts that Conditional Access policies will protect.

View & Configure Network

Configure trusted locations, named locations, countries, regions, and IP ranges to control access based on network location.

View & Configure Conditions

Configure policy conditions such as device platforms, client apps, sign-in risk, user risk, device filters, and authentication flows.

View & Configure Grant Access or Block Access

Configure access controls such as requiring Multifactor Authentication (MFA), compliant devices, authentication strength, or blocking access.

View & Configure Session Controls

Configure session controls including sign-in frequency, persistent browser sessions, Continuous Access Evaluation (CAE), and application restrictions.

Test Policies Safely Using Report-only Mode

Test Conditional Access policies in Report-only mode to evaluate how they would affect users without enforcing access restrictions.

Validate Results in Sign-in Logs

Review Sign-in Logs to verify whether Conditional Access policies were applied, determine policy results, and troubleshoot authentication or access issues.

Microsoft Entra ID Self-Service Password Reset (SSPR)

Self-Service Password Reset Configuration & Support

Learn the essential Self-Service Password Reset (SSPR) administration tasks in the Microsoft Entra admin center, including enabling SSPR, configuring user scope, authentication requirements, user registration, notifications, helpdesk information, and validating password reset functionality.

Enable or Disable SSPR

Enable or disable Self-Service Password Reset (SSPR) for all users or selected groups to allow users to reset their passwords without contacting the helpdesk.

Configure SSPR Scope

Configure whether Self-Service Password Reset (SSPR) is available to all users or only selected security groups within the organization.

Configure Authentication Methods for SSPR

Configure the authentication methods available for Self-Service Password Reset (SSPR) through the Authentication Methods policy, including Microsoft Authenticator, SMS, Voice Call, FIDO2 Security Keys, Passkeys, and Temporary Access Pass.

Configure Number of Authentication Methods Required

Configure whether users must verify their identity using one or two authentication methods before completing a Self-Service Password Reset (SSPR).

Configure User Registration Settings

Configure SSPR registration settings by requiring users to register authentication methods during sign-in and specifying how often they must re-confirm their authentication information.

Configure Notifications

Configure email notifications to inform users and administrators when passwords are reset, helping improve account security and monitoring.

Configure Custom Helpdesk Information

Configure custom helpdesk contact information and support links displayed to users during the Self-Service Password Reset (SSPR) process.

Test and Validate SSPR Configuration

Test the Self-Service Password Reset (SSPR) experience to verify that authentication methods, registration requirements, notifications, and password reset policies are working as expected.

Microsoft Entra ID Devices

Devices Management & Support

Learn the essential device administration tasks in the Microsoft Entra admin center, including viewing and managing devices, understanding device join types, checking device status and ownership, reviewing device properties, recovering BitLocker keys, viewing Local Administrator Password Solution (LAPS) passwords, and auditing device activities.

Find and View Devices

Search for and view registered, Microsoft Entra joined, and hybrid joined devices managed within the organization.

Understand Device Join Types

Learn the differences between Microsoft Entra Joined, Microsoft Entra Hybrid Joined, and Microsoft Entra Registered devices and their respective use cases.

Check Device Status

Review device status, including whether a device is enabled, disabled, compliant, managed, and synchronized with Microsoft Entra ID.

Identify Device Ownership

Identify the user assigned to a device and determine device ownership for troubleshooting and administrative purposes.

View Device Properties

Review device details such as operating system, device ID, join type, trust type, ownership, registration date, and last sign-in activity.

Enable, Disable, or Delete a Device

Enable, disable, or delete devices to control organizational access and manage the device lifecycle.

Restore Deleted Devices

Restore recently deleted devices when available to recover device records and maintain organizational access.

View Device BitLocker Recovery Keys

View BitLocker recovery keys stored in Microsoft Entra ID to assist users in unlocking encrypted Windows devices.

View Local Administrator Password Recovery (Windows LAPS)

Retrieve the Windows Local Administrator Password Solution (LAPS) password for supported devices when administrative access is required.

Check Device Audit Logs

Review device audit logs to track administrative actions such as device registration, updates, deletion, enablement, and other management activities.

Microsoft Entra ID Enterprise Applications

Enterprise Applications Basic Management & Support

Learn the essential Level 1 Microsoft Entra Enterprise Application administration tasks, including searching and viewing enterprise applications, managing user and group assignments, reviewing assigned application roles, checking Single Sign-On (SSO) configuration, verifying application properties, and monitoring application sign-in activity.

Search and View Enterprise Applications

Locate enterprise applications and review their Overview, Properties, Users and Groups, Application Roles, and Sign-in Logs.

Assign Users or Groups to an Application

Assign users or security groups to an enterprise application so they can access the application based on organizational requirements.

Remove User Assignments

Remove users or groups from an enterprise application to revoke access when it is no longer required.

Verify User & Group Assignments

Verify that the correct users and groups have been assigned to an enterprise application and confirm access permissions.

View Assigned Application Roles

Review the application roles assigned to users and groups to ensure the appropriate level of access.

Review Sign-in Logs

Review application sign-in logs to monitor authentication activity, identify failures, and assist with troubleshooting.

View Single Sign-On (SSO) Configuration

Review the configured Single Sign-On (SSO) settings, including the sign-on method and related configuration details.

Verify Application Properties

Verify application properties such as the application name, status, visibility, assignment requirements, and other configuration settings.
