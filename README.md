# Microsoft Entra ID Administration & Support

A hands-on learning portfolio focused on Microsoft Entra ID administration, identity and access management (IAM), authentication, device management, and security. This project documents my learning journey through practical administration, configuration, and troubleshooting labs using the Microsoft Entra admin center.

## Overview

This portfolio is designed to build practical Microsoft Entra ID administration skills commonly required for Level 1 and Level 2 IT Support, Help Desk, Service Desk, and Identity & Access Administrator roles.

The project focuses on real-world identity administration and security tasks performed through the Microsoft Entra admin center, including user and group management, authentication, device management, application access, and identity security.
